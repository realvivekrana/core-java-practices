## ▶️ How to Run Java Programs

Compile a Java file:

``` bash
javac HelloWorld.java
```

Run the compiled program:

``` bash
java HelloWorld
```

Example:

``` java
public class HelloWorld {

    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

Output:

``` text
Hello World
```

## 💡 Practice Approach

For every topic:

1.  Learn the concept
2.  Write the code yourself
3.  Run and debug the program
4.  Solve small problems
5.  Commit the changes to GitHub
6.  Move to the next topic

The goal is not just to read Java --- it is to **write, debug, and
understand Java code**.
